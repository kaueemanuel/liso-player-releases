# Liso Player

Player de vídeo para Windows com interpolação de quadros na GPU (vídeo mais fluido, até a taxa do monitor).

## Instalar

1. Baixe o `Liso.Player_x.y.z_x64-setup.exe` da [versão mais recente](https://github.com/kaueemanuel/liso-player-releases/releases/latest).
2. Execute. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** → **Executar assim mesmo** (o instalador ainda não tem certificado pago).

O app se atualiza sozinho: quando houver versão nova, ele avisa ao abrir.

Este repositório só guarda os instaladores; o código-fonte é privado.
